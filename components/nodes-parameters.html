Nodes parameters

The parameters of a node canvas's sheet, set out beside the canvas.

NodesParametersComponent · type key graph.nodes-parameters · Graph

The set is the sheet's own, UINodeDocument.Parameters, saved and undone with it; the canvas writes the rows. Only a canvas such a component is aimed at offers a pin's Add to parameters. Where it stands is the page's: a column beside the canvas, a pane the viewer moves (PaneContainerComponent).

new NodesParametersComponent("nodes-parameters")
