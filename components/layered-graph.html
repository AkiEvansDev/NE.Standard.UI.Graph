Layered graph

A graph of the application's nodes and the links between them, laid out in layers.

LayeredGraphComponent · type key graph.canvas.layered · Graph

Items is a bound collection; a node the viewer has not placed is positioned by the layout.

new LayeredGraphComponent("layered-graph")

Events

OnMenuEntry(string command, string argumentName = "key")
Runs command when an entry the application put into any of the canvas's menus is clicked; the entry's id is the command's key.
The canvas's own entries never reach it.
OnMenuEntry(string command, params KeyValuePair<string, UIActionArgument>[] arguments)
The same, naming what the command takes: UIGraphArguments.Entry, UIGraphArguments.TargetKind and UIGraphArguments.Target.
The target is named for an entry of an item's, a group's or an edge's menu.
